# IPTV playlist

Заготовка для личного M3U-плейлиста, который можно опубликовать через GitHub Pages и открыть на Smart TV.

## Файлы

- `playlist.m3u` - основной плейлист для IPTV-приложения.
- `index.html` - простая страница GitHub Pages со ссылкой на плейлист.
- `.nojekyll` - отключает Jekyll, чтобы GitHub Pages отдавал файлы как есть.

## URL плейлиста

После публикации через GitHub Pages плейлист будет доступен по адресу:

```text
https://<github-username>.github.io/iptv/playlist.m3u
```

Если репозиторий будет называться иначе, замените `iptv` на имя репозитория.

## Как добавить канал

Добавляйте каналы в `playlist.m3u` парами строк:

```m3u
#EXTINF:-1 tvg-id="channel-id" tvg-name="Название" group-title="Группа",Название
https://example.com/live/channel/index.m3u8
```

Полезные поля:

- `tvg-id` - идентификатор канала для EPG.
- `tvg-name` - название канала для EPG.
- `tvg-logo` - URL логотипа канала.
- `group-title` - группа в IPTV-приложении.

## Дальнейшие шаги

1. Заменить примеры в `playlist.m3u` на реальные URL потоков.
2. Запушить репозиторий на GitHub.
3. Открыть настройки репозитория: `Settings` -> `Pages`.
4. В `Build and deployment` выбрать `Deploy from a branch`.
5. Выбрать ветку `main` и папку `/root`, затем нажать `Save`.
6. Подождать деплой GitHub Pages.
7. Открыть `https://<github-username>.github.io/iptv/playlist.m3u` и проверить, что файл скачивается или отображается.
8. В IPTV-приложении на Smart TV добавить этот URL как внешний плейлист.

## Важно

Используйте только легальные источники потоков. Некоторые Smart TV IPTV-приложения кешируют плейлист, поэтому после изменений может понадобиться вручную обновить плейлист в приложении.
